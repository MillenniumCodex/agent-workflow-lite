# Agent Workflow (Lite)

A small, layered AGENTS.md / CLAUDE.md setup for AI coding agents (Claude Code, Codex, Gemini CLI, Cursor). Agents load a 2 KB entry file and a 2 KB core on every task instead of one giant prompt.

**Included free:** the entry files, the core and a blank project profile. Copy them into your repo root and fill in the placeholders.

**Full kit:** seven on-demand modules (context recovery, verification, delegation, measurement, workflows, adoption), JSON task and checkpoint templates, worked examples and a validator. Link: coming soon. Watch this repo for the release.
